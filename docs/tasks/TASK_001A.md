# Task 001A — 단일 교시의 정각·지각 경계 판정

**현재 상태: AI 구현으로 시각 비교와 명시적 입력 검증을 보완, 학생 독립 수행 과제는 미완료.** 사용자의 ‘너가 해’와 후속 ‘계속’에 따라 AI가 타입·형식·시간대·달력 검증을 구현하고 기존 세 사례를 포함한 67개 테스트를 실행했다. [현재 입력 규칙과 확인 범위](../TIMESTAMP_INPUT.md). 기능·검사는 AI 작성/실행이며 학생의 독립 설계·테스트 작성·직접 실행은 아직 확인하지 않았다. Starter는 다른 도메인의 자료다. 아래 안내 연습 이력의 ‘미완료’는 각 단계 당시의 상태다.

후속 진행: 학생이 날짜 변환 실패 검사도 입력했고, 시작 시각 검사에 인식 시각 변수가 남아 있던 부분을 AI 검토 후 수정했다. 정상 시각 세 건과 잘못된 인식/시작 시각 두 건의 총 다섯 사례를 AI가 확인했다. 입력 누락·타입·형식 검증은 여전히 미완료다. `evidence/task-001a-guided-02/`에 해당 단계의 소스와 검사·한계 기록을 보관한다.

다음 단계 진행: 학생이 AI 제공 null·undefined 누락 검사를 입력했고 AI가 기존 다섯 사례와 누락 네 사례의 총 아홉 사례를 확인했다. 타입·엄격한 형식 검증은 미완료다. `practice/task-001a.test.mjs`에 AI가 작성한 정각 테스트 예시 한 개를 두었다. 학생은 이를 참고해 **직접 고른 다른 시각, 예상 결과, 검사 목적**으로 새 테스트를 작성할 차례다. 아직 학생 작성 테스트나 독립 구현으로 계산하지 않는다.

## 작은 목표

2026-11-18 사용자 명시 요청에 따른 AI 작업: 사용자가 정각 테스트 추가를 ‘너가 해’라고 요청해 AI가 18:25:00→false 테스트를 직접 추가했다. 기존 18:20·false와 사용자 선택 18:26·true를 포함한 세 테스트의 실행·출처는 `evidence/task-001a-ai-equality-01/`에 기록한다. 이번 정각 테스트는 학생 작성으로 계산하지 않으며 타입·형식 검증 등 전체 과제는 여전히 미완료다.

### 시작 파일

`practice/task-001a.mjs`는 AI가 만든 틀과 학생의 안내 입력 연습에서 시작했고, 현재 입력 검증 구현은 사용자 요청으로 AI가 작성했다. 명시적인 시간대가 있는 유효한 시각 문자열만 받아 비교 결과를 boolean으로 반환한다. 학생의 독립 구현·직접 실행은 아직 확인하지 않았다. 최초 연습은 `evidence/task-001a-guided-01/`, 현재 검증은 `evidence/task-001a-strict-input-01/`에 구분해 보존한다.

처음 할 일은 파일을 열어 입력 두 개(`recognizedAt`, `startAt`)를 확인하고 반환할 분류 이름을 정하는 것이다. 예시 입력은 `2026-11-17T18:25:01+09:00`과 `2026-11-17T18:25:00+09:00`이다. 이 예시의 결과는 ‘시작 이후 / 사유 확인 필요’에 해당하며 최종 지각 확정은 아니다. 이 문단과 예시 역시 AI가 제공한 설명이다.

학생이 **해당 한국 날짜의 1교시 시작 18:25**를 기준으로 인식 시각을 판정하는 함수 하나를 직접 설계하고 검증한다. 최신 요구는 시각 제한 없이 하루 한 건 출석이다. 교시 자동 선택·2·3교시 별도 출석은 범위 밖이며 18:10 접수 시작 제한도 없다. 센서 없이 가상 시각만 사용한다. **이 함수는 시간 기준 분류만 한다. 시작 이후라는 결과가 최종 지각 확정은 아니며, 외출 복귀 직후 출석은 확인 후 지각에서 제외한다.** 외출 예외 확인, 날짜별 저장·중복 처리, 학생 식별, 미출석 및 알림은 후속 과제다. 이 비교 함수만으로 운영 시스템까지 완성됐다고 주장하지 않는다.

## 학생이 먼저 정할 것

1. 사용할 언어와 함수 입력·출력 형식을 정한다. 새 의존성 없이 실행할 수 있는 작은 구현을 권한다.
2. 날짜와 시간대가 포함된 시간을 어떻게 표현할지 적는다. 운영 기준은 `Asia/Seoul`, 정밀도는 초 또는 밀리초 중 하나를 명시한다. 시간대가 없는 문자열·잘못된 날짜를 암묵적으로 변환하지 않는다.
3. 사용자가 정한 **언제든 하루 한 건** 규칙을 결정표에 반영한다. 한국 시간 00:00부터 18:25 정각까지는 시간 기준 정상, 그 이후 자정 전까지는 시작 이후로 분류한다. 시작 이후는 외출 예외를 확인할 대상이며 자동 지각 확정이 아니다. 이전 15분 제한은 적용하지 않는다. 하루 한 건 저장·외출 확인은 후속 과제이며 사용자 요구사항과 학교 운영 승인 여부를 구분한다.
4. 누락·유효하지 않은 시각의 오류 반환 방법을 정한다. 누락된 인식 시각을 이 함수가 결석으로 확정해서는 안 된다.

## 반드시 만족할 요구사항

사용자가 제공한 1교시 시작 시각 18:25를 사용한다. 아래 날짜와 인식 이벤트는 테스트용 합성 입력이며 실제 출석 기록이 아니다. `2026-11-16T18:25:00+09:00`을 시작으로 두면:

| 입력 사례 | 요구되는 판단 |
|---|---|
| 00:00:00 | 새 한국 날짜의 정상 출석 |
| 18:09:59 | 정상 출석; 과거 18:10 제한 적용 금지 |
| 18:10:00 | 정상 출석 |
| 18:24:59 | 정상 출석 |
| 18:25:00 정각 | 지각 아님 |
| 18:25:01 | 시작 이후; 최종 지각 여부는 외출 예외 확인 대상 |
| 23:59:59 | 해당 한국 날짜의 시작 이후; 최종 지각 여부는 외출 예외 확인 대상 |
| 날짜·시각 누락 또는 형식 오류 | 명시적 오류 또는 미확인; 출석/결석 조작 금지 |
| 같은 순간을 나타내는 `09:25:00Z`와 `18:25:00+09:00` | 같은 결과 |

학생은 자신의 정밀도에 맞는 시작 직전·정각·직후 사례를 추가한다. 문자열 정렬만으로 시간을 비교해도 되는지, 다른 날짜·시간대에서 어떤 문제가 생길지 설명한다.
