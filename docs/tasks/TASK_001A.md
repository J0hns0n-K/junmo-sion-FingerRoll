# Task 001A — 단일 교시의 정각·지각 경계 판정

**상태: 학생 수행 대기.** 이 과제 설명은 AI가 작성했다. 아직 학생이 설계·구현·테스트했다는 증거는 없다. Starter는 다른 도메인의 코드이므로 이 과제를 그 코드의 기존 버그 수정으로 표현하지 않는다.

## 작은 목표

학생이 **해당 한국 날짜의 1교시 시작 18:25**를 기준으로 인식 시각을 판정하는 함수 하나를 직접 설계하고 검증한다. 최신 요구는 시각 제한 없이 하루 한 건 출석이다. 교시 자동 선택·2·3교시 별도 출석은 범위 밖이며 18:10 접수 시작 제한도 없다. 센서 없이 가상 시각만 사용한다. 날짜별 저장·중복 처리, 학생 식별, 미출석 및 알림은 후속 과제다. 이 비교 함수만으로 하루 한 건 저장이나 운영 시스템까지 완성됐다고 주장하지 않는다.

## 학생이 먼저 정할 것

1. 사용할 언어와 함수 입력·출력 형식을 정한다. 새 의존성 없이 실행할 수 있는 작은 구현을 권한다.
2. 날짜와 시간대가 포함된 시간을 어떻게 표현할지 적는다. 운영 기준은 `Asia/Seoul`, 정밀도는 초 또는 밀리초 중 하나를 명시한다. 시간대가 없는 문자열·잘못된 날짜를 암묵적으로 변환하지 않는다.
3. 사용자가 정한 **언제든 하루 한 건** 규칙을 결정표에 반영한다. 한국 시간 00:00부터 18:25 정각까지는 정상 출석, 그 이후 자정 전까지는 지각이다. 이전 15분 제한은 적용하지 않는다. 하루 한 건 저장은 후속 과제이며 사용자 요구사항과 학교 운영 승인 여부를 구분한다.
4. 누락·유효하지 않은 시각의 오류 반환 방법을 정한다. 누락된 인식 시각을 이 함수가 결석으로 확정해서는 안 된다.

## 반드시 만족할 요구사항

사용자가 제공한 1교시 시작 시각 18:25를 사용한다. 아래 날짜와 인식 이벤트는 테스트용 합성 입력이며 실제 출석 기록이 아니다. `2026-11-16T18:25:00+09:00`을 시작으로 두면:

| 입력 사례 | 요구되는 판단 |
|---|---|
| 00:00:00 | 새 한국 날짜의 정상 출석 |
| 18:09:59 | 정상 출석; 과거 18:10 제한 적용 금지 |
| 18:10:00 | 정상 출석 |
| 18:24:59 | 정상 출석 |
| 18:25:00 정각 | 지각 아님 |
| 18:25:01 | 지각 |
| 23:59:59 | 해당 한국 날짜의 지각 |
| 날짜·시각 누락 또는 형식 오류 | 명시적 오류 또는 미확인; 출석/결석 조작 금지 |
| 같은 순간을 나타내는 `09:25:00Z`와 `18:25:00+09:00` | 같은 결과 |

학생은 자신의 정밀도에 맞는 시작 직전·정각·직후 사례를 추가한다. 문자열 정렬만으로 시간을 비교해도 되는지, 다른 날짜·시간대에서 어떤 문제가 생길지 설명한다.
