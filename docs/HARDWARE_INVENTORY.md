## 구성 판단

구매한 중심 보드는 **Raspberry Pi Zero 2 W**다. 앞으로 아두이노 UNO/NANO 보드를 전제해 배선·프로그램을 안내하지 않는다. 상품명에 ‘아두이노’가 들어간 센서·점퍼선과 중심 보드 종류를 구분한다. 센서와 이 보드의 전기적·통신 호환성을 실제 확인한 것은 아니다.

[공식 Zero 2 W 제품 정보](https://www.raspberrypi.com/products/raspberry-pi-zero-2-w/)는 microSD 슬롯과 micro USB 전원 포트를 설명한다. 공식 일반 보드 설명의 미장착 헤더와 별개로, 구매한 판매 페이지는 with Headers 변형을 명시한다.

3. 센서 실물 표시·배선 자료와 보드 전기 규격을 대조한 후 연결·통신 확인 절차를 만든다. 아직 전압·핀 번호·선 색을 단정해 안내하지 않는다.
