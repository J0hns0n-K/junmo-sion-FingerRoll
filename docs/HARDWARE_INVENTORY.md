## 구성 판단

11월 17일 당시 취소된 보드는 **Raspberry Pi Zero 2 W**였고 사용할 중심 보드는 미정이었다. 11월 23일에는 **Pico H를 주문한 것으로 보고받았지만 아직 수령 전**이다. 상품명에 ‘아두이노’가 들어간 센서·점퍼선과 중심 보드 종류를 구분한다. 센서와 Pico H의 실제 전기적·통신 호환성을 검증한 것은 아니며 전압·핀 번호·선 색을 확정해 배선하지 않았다.

Pico H는 핀 헤더가 부착된 마이크로컨트롤러이며 USB·UART를 지원한다. [공식 Pico 문서](https://www.raspberrypi.com/documentation/microcontrollers/pico-series.html). 이번 계획에는 Pico의 내장 메모리를 사용하며 별도 SD 카드·Raspberry Pi OS·USB–UART 변환기는 추가하지 않는다. 센서 중계 프로그램을 준비하고 실제 센서의 전원·핀 표기와 대조한 뒤 통신부터 확인할 계획이다.

[공식 Zero 2 W 제품 정보](https://www.raspberrypi.com/products/raspberry-pi-zero-2-w/)는 microSD 슬롯과 micro USB 전원 포트를 설명한다. 공식 일반 보드 설명의 미장착 헤더와 별개로, 구매한 판매 페이지는 with Headers 변형을 명시한다.

## 현재 다음 단계 — 보드 도착 후 수행

1. 센서와 분리한 상태에서 Pico H 단독으로 USB 인식·기존 케이블의 데이터 전송 여부를 확인한다.
2. 정확한 보드 모델을 확인하고 보드용 센서 통신 프로그램을 준비·설치한다. 아직 준비·설치 완료로 기록하지 않는다.
3. 센서 전압·핀 표기와 보드 규격을 대조한 뒤 배선하고, 지문 등록 없는 정보 조회로 통신을 검사한다.
4. 실제 지문 등록 전 별도 학교 운영·개인정보 검토를 거친다. 인식 결과와 출석 화면의 연동은 실제 검사 이후 단계다.
