# 노트북 가상 출석 화면

2026-11-18, 사용자 ‘계속’ 요청으로 AI가 구현·검사했다. 가상 ID S001~S004만 사용한다. 실제 학생 정보·지문·메시지 전송은 없다. 화면과 검사는 학생 독립 구현으로 계산하지 않는다.

## 실행

Node.js가 있는 작업 폴더에서 다음을 실행한다. 추가 패키지 설치는 필요 없다. 확인 환경은 Node v24.22.1이다.

```powershell
node scripts/demo-web.mjs
```

브라우저에서 `http://127.0.0.1:4318`을 연다. 종료는 실행 창에서 `Ctrl+C`다. 포트가 이미 사용 중이면 시작에 실패하므로 기존 데모 실행 창을 먼저 확인한다. 검증용 서버는 확인 후 종료했다.

이 화면의 시계는 **2026-11-18 18:24:00에서 시작하는 가상 시계**다. 실제 노트북 현재 시각이 아니며 경과 시간만큼 진행한다. ‘시계 1분 앞으로’로 앞으로 이동할 수 있다. 날짜 변경 혼동을 피하려고 가상 날짜의 23:59:59.999에서 멈춘다. 화면 기록과 확인 이력은 메모리에만 있고 **서버를 다시 켜면 초기화**된다. 브라우저 새로고침만으로는 서버의 기록이 지워지지 않는다. 별도 파일 저장 데모의 SQLite 파일과 연결하지 않는다.

## 확인 순서

1. 18:25 전에 S001의 ‘가상 출석’을 누른다. 정상 출석 한 건이 생긴다.
2. 시계를 1분 앞으로 옮긴다. 기록 없는 학생이 미확인으로 바뀐다. S001을 다시 눌러도 첫 시각과 상태를 유지한다.
3. S002의 ‘사유 확인’에서 ‘따로 전달받은 사유’를 기록한다. 사유 확인·출석 전으로 표시되며 출석 건수는 늘지 않는다.
4. S003을 늦게 가상 출석시킨다. 지각 여부 확인으로 남는다. ‘외출 복귀 직후 출석 확인’ 사유를 기록해도 자동 면제하지 않는다.
5. 담당자 역할의 사용자가 ‘지각 면제’를 누른 뒤 상태·원 인식 시각·이력을 확인한다. ‘사유 취소’는 다시 검토 상태로 돌리며 과거 이력을 보존한다.
6. S004는 미확인으로 남는다. 자동 결석·사생회 통보는 발생하지 않는다.

정상/지각 기준은 내부에서 밀리초까지 비교한다. 화면의 시각 표시는 초 단위이고 원문·정밀 시각은 API 기록에 보존한다. 사유는 세 종류의 최소 분류만 받으며 상세 건강·상담 메모 입력란은 없다.

명단은 열린 화면에서 통상 1초 간격으로 조회하고, 버튼 작업 뒤 즉시 갱신한다. 브라우저 절전·백그라운드 제한·프로세스 중단 등에 따른 지연이 있으므로 정확한 시각의 운영 알림을 보장하지 않는다. 18:25는 미확인 검토 시작일 뿐 접수 마감이 아니다. 연결이 끊기면 오래된 명단으로 판단하지 말라는 경고를 표시한다.

## 접근 범위와 미완료

서버는 `127.0.0.1`에만 연결한다. 허용한 Host·Origin을 검사하고 변경 요청에 같은 Origin, JSON 형식, 별도 요청 헤더를 요구한다. 다른 출처 허용(CORS)과 외부 스크립트는 사용하지 않는다. 고정 가상 명단 밖 ID, 클라이언트가 지정한 인식 시각·확인자, 상세 메모, 큰 입력을 거부한다. 확인 충돌은 409로 거부해 최신 명단에서 다시 검토하게 한다.

이 제한은 학교 운영용 계정 인증·역할 권한이 아니다. 같은 노트북의 프로세스는 데모에 접근할 수 있다. `DEMO_OPERATOR`는 고정 가상 기록자일 뿐 실제 신원을 확인하지 않는다. 서버 공개·포트 전달·실제 데이터 입력은 범위 밖이다. 학교 승인·동의·대체 출석·담당자 로그인·권한·보유기간·삭제·센서와의 신뢰 가능한 연결을 검증하기 전까지 실제 운영에 사용하지 않는다.

별도 [브라우저 확인 기록](../evidence/laptop-ui-01/browser-check.json)과 [연결 중단 확인](../evidence/laptop-ui-01/disconnection-check.json)은 위 자동 검사 수에 더하지 않는다. 관측한 DOM 너비 984·300에서 페이지 전체의 가로 넘침이 없었고 작은 화면의 표는 내부 가로 스크롤을 사용한다. 화면 크기 재정의 중 찍힌 두 이미지는 런타임 잘림이 있어 시각 품질 근거로 사용하지 않는다. 기본 크기로 복원한 [화면 결과](../evidence/laptop-ui-01/board-result.jpg)를 별도로 보존했다. 이 증거는 합성 소프트웨어 동작이며 실제 센서·학생 직접 실행·학교 운영·성능 개선의 증거가 아니다.
